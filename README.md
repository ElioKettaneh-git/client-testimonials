## Formatting and permissions

The testimonials were originally provided in formats such as WhatsApp messages, Word documents, and plain text. They were reformatted into PDF documents for consistent presentation, without changing the original written feedback. Some contact information has been redacted for privacy.

**Publication permission:** Publish only testimonials for which the relevant client has explicitly approved public sharing. Permission to reformat a testimonial does not necessarily include permission to publish it online.
